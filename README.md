# Excel Formula Formatter

A simple, free tool for making long Excel formulas easier to read. Format, highlight, and minify formulas directly in your browser.

## Features

- Format formulas with readable indentation and line breaks.
- Minify formulas into a compact form.
- Syntax highlighting for functions, references, numbers, and text.
- Smart and expanded formatting layouts.
- Choose 2 spaces, 4 spaces, or tabs for indentation.
- Copy the result back into Excel.
- Works with modern formulas such as `LET`, `FILTER`, and `XLOOKUP`, including structured table references.
- Preserves quoted text and comma/semicolon separators.
- Works offline with no installation or external dependencies.

## How to use

1. Open `index.html` in your browser, or visit the published website.
2. Paste an Excel formula into the input box.
3. Click **Format formula** or **Minify**.
4. Click **Copy formula** to paste the result into Excel.

## Notes

The formatter changes how formulas are displayed; it does not calculate formulas or replace Excel's formula validation. For critical work, check formatted formulas in Excel.
